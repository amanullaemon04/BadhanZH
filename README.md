BADHAN ZH – Hall Blood Donor Directory
A mobile-friendly and efficient blood donor management system designed to connect donors and seekers seamlessly.
Key Features
 * 🔍 Smart Filter & Search: Easily find blood donors based on blood group, hall/location, city, and real-time availability.
 * 👥 Donor Registration: Seamless onboarding form for new donors to register their contact and location details.
 * 🛡️ Admin Control Panel: Secured admin dashboard backed by Supabase authentication to verify, approve, and manage donor entries.
 * 💬 Feedback System: Dedicated channel for users to submit feedback and suggestions, directly reviewable from the admin panel.
 * 📖 Donor Guidelines & Stats: Comprehensive eligibility information, health tips, and platform donation metrics.
 * ⚡ Tech Stack: HTML5, Modern CSS3 (Mobile-first responsive design), Vanilla JavaScript, Supabase (PostgreSQL Database & Auth), and Cloudflare Workers.
